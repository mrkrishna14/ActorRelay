Effects cover TK-101 (levelPct, tempC), LV-101 (positionPct), E-101 (dutyKw), TV-101 (positionPct, steamKgH, headerBarg). Dates 2024-01-01 .. 2026-03-07 (tested within 2024-01-01..2026-12-31).

### before / after / ticksToSettle (exact definitions)
One tick = 18 `TankPlant.scan()` calls. Each event builds a fresh `TankPlant` at the prior speed, header and feed temp, runs 144 scans (8 ticks) to precondition, then steps P-100 and simulates 15 ticks (`SETTLE_HORIZON`).
- `before`: metric value at the step instant (tick 0, end of preconditioning).
- `after`: value at tick 3 for LV-101 positionPct (the demo rule is a within-three-ticks observation), tick 5 for every other metric.
- `ticksToSettle`: with `series[t]` = value after t ticks (t = 0..15) and `final = series[15]`, band = `max(0.02*|final|, 0.5)` units; ticksToSettle = smallest k in 0..15 such that `|series[t] - final| <= band` for every t >= k (`gen_history.settle_tick`). 0 means the metric never left the band.
- Distribution: LV-101 1-9 (mostly 2 or 6-8: fast saturation then back-off as LIC-101 recovers), TK-101 levelPct 0-10, tempC 0-10, TV-101 positionPct 0-7, steamKgH/dutyKw 0-11, headerBarg always 0 (header is a fixed boundary condition).
